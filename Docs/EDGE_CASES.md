# Edge Case Matrix (Brief §14 Sweep)

Comprehensive verification and handling matrix for all 20 edge cases specified in Section 14 of `PROJECT_BRIEF.md`.
Rule: *Never crash on single media failure. Kiosk must run unattended for days without stranded UI or infinite spinners.*

### Special Scenario Sweeps

1. **Screensaver.mp4 removed mid-slideshow**:
   - `SlideshowScreen` detects deletion via media watcher (`screensaver === null`).
   - Active track detects failure on ended or error; calls `controller.markFailed(SCREENSAVER_TRACK_ID)`.
   - Controller logs warning and falls back to shuffle mode without dropping the screen.
   - If no shuffle items exist either, cleanly dispatches `FATAL_ERROR` to display `ErrorScreen`.

2. **Folder unplugged during active playback**:
   - Media watcher receives deletion / unmount signal; `handleMediaChangedEvent` detects absence of active item.
   - Player clears selection and cleanly returns to `GALLERY` with `EmptyScreen` (`NO_FOLDER`).
   - If active video throws `MediaError` before watcher fires, error overlay is displayed with immediate "Back to Gallery" tap target and auto-recovery on idle timeout.

3. **Android Storage Permission Revocation**:
   - Monitored on every `focus` and `visibilitychange` event via `checkStoragePermission()`.
   - Revocation triggers instant teardown of active playback/slideshow and mounts `EmptyScreen` (`NO_PERMISSION`) with one-touch button deep-linking to system settings.
